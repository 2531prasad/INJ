# Source map

INJ remains a build-free static game. `index.html` contains the interface markup; local styles and classic deferred scripts contain the implementation. Classic scripts keep both direct file opening and ordinary static hosting available.

## Read for a change

1. Read `inj.md` for the current product contract.
2. Pick the subsystem below. Read its dependency header if the change crosses a boundary.
3. Run the quick browser command or relevant functional suites from [testing.md](testing.md); structure and production smoke are included. Opt into `--full` only when exhaustive validation is needed.

## Module contract

Each file registers its API on **one internal namespace**, `window.INJ`. Its `App` parameter points to that object. Local names remain file scoped; exports are listed at the end. Dependencies are explicit `App.foo` references rather than globals whose origin is hidden.

Objects such as `game`, actors and input keep their identity during reset. The old mutable width and last-frame scalars now live in `world.width` and `clock.last`, so every file sees their current values. Menu-only focus state and the display observer's scheduling flag stay private.

There are deliberate runtime cycles: combat updates control labels; input dispatches player actions; round flow opens the loss dialogue; UI calls the renderer and round reset. Those calls resolve through `App` **when invoked**. Registration does not start the game. `js/main.js` runs after every API exists and calls initialization exactly once. This avoids capturing undefined functions from a later script without needing a bundler or asynchronous loader.

The namespace is an internal implementation API, not a saved-game or external plugin format. Add a subsystem export only when another subsystem or a meaningful integration check needs it. Avoid duplicating mutable values in separate modules.

## Local save and earned passive boundary

[Progression contract](progression.md) defines the version-1 `inj-progress` save and exact passive rules. `progression.js` registers after state; `passive.js` after teleport and before fighter rendering. All registration finishes before `initMenus` loads the save once, resets the checkpoint encounter, and leaves the profile paused. `resetRound` writes checkpoint progress; `endRound` records results once and saves a genuine Colossus KO reward before the victory panel. No fight/actor snapshots or frame-by-frame writes are stored. Restart preserves achievements while checkpointing level one; bad/unavailable/future storage cases are handled without preventing play.

`state.js` owns shared `progress` plus transient actor `burstHits`, `burstWindow`, `burst`, `burstStun`. `combat.applyHit` counts eligible surviving incoming hits, clears the incoming chain on guard/clean counter-hit, and protects the active burst. `passive.js` grows INJ to 1.6× over 100 ms and shrinks over 300 ms, using a one-shot 130-unit peak pulse, zero damage, and one second of enemy stun. `fighters.js` reuses pose 10 and applies the same foot-anchored scale as `hurtbox`; giant rendering reuses its existing recoil pose. `controlDummy` processes dedicated stun before any AI dispatcher. This earned effect explicitly overrides giant hit poise; ordinary attacks keep the prior poise rule.

`engine.js` steps the passive in active combat before controllers. The player controller waits through the burst while preserving held directions. KO/round/phase reset clears transient burst/stun fields; pause/hit-stop freeze them. `menus.js` owns first-unlock victory text and the compact saved-passive status. The unlocked victory variant uses compact spacing so Next Round fits inside the arena at 320 px. No sprites, action buttons or extra animation assets are added.

## Goldline encounter boundary

`dummy` remains the live opponent object for all rounds; check `kind` / `isR8` rather than its variable name. Round two uses `LEVEL_TWO`; round three configures the R8; round four configures Blue Velvet and round five onward configures the Velvet Colossus. Combat delegates its hurtbox and attack physics, while shared damage/guard still decides outcomes. Empty car health enters `transform`, clears attacks/input/projectiles and freezes simulation until the robot is installed. The first form displays one turquoise bar and no reserve/phase label; transformation keeps that depleted bar until the robot reveals a new gold bar. The second form refills both INJ and robot health, preserves INJ Shadow charge and Nitro meter, clears the hit chain, resets the phase clock to 99 and resumes with brief entry protection. The robot recognizes repeated low strikes, shields during its counter windup, closes against projectiles, punishes recovery, and uses a faster/reaching jet uppercut against jumps. Its shield beat varies from 160–300 ms before a ground counter; after a stagger it spends 10–65 ms reassessing before its next offensive decision. Incoming damage is now 85% of base and outgoing damage 130%, with the same 140 HP. Its 480–780 ms burst rests include a guaranteed 320 ms opening before defensive reactions resume. Timer expiry loses to the boss in either form; both pools must be cleared. The engine freezes transformation when paused. Keep these rules in `encounters.js` and `rounds.js`, not in renderer callbacks.

## Held directions and command boundary

[Input contract](input.md) defines the player state/command rules and research sources. `controls.js` tracks held directions independently from one pending action plus a jump request. Opposing directions resolve to neutral. Presses snapshot modifiers and have 220 ms deadlines on `game.inputTime`; `consume()` returns a snapshot or null, never a wall-clock check. New non-jump requests replace older ones, and reset clears clock/commands/held inputs. Space now participates in held jump alongside W/Up and the joystick cone.

`movement.controlPlayer` processes committed attack/hitstun/knockdown time first, advances the input clock with each simulation segment, and resolves new commands at the first legal boundary using any remaining time in that frame. Grounded attacks stay rooted. Jump resolves before the next queued attack; ordinary aerial attacks keep the same steering as an empty jump, while authored drive moves suppress extra steering. Hit-stop freezes the controller/clock, and pause/cutscenes clear input. Low guard uses its crouching hurtbox. `combat.startAttack(f, key, command?)` accepts optional down context for Nitro; other callers are unchanged. No source sprite changes or rendering-driven control logic are introduced.

## Player combo and ability boundary

`state.js` owns the independent `player.charge` (0–3 Shadow charge) and `player.meter` (0–100 Nitro energy). Shared combat credits clean hits, applies the escalating combo multiplier before armor, and clears a chain on interruption/block/whiff. `game.hits` and its 1.4-second `hitTimer` drive the HUD. Invalid/invulnerable hits do not extend the chain. Round resets clear both resources; robot reveal restores health while carrying them forward.

`controls.js` owns NITRO / Q and rejects that action below full meter; `movement.js` dispatches it standing, crouching and airborne. The kick costs 100 on attack start, travels forward during its active window and can be blocked or interrupted. `combat.js` integrates only the elapsed active portion of each step, so the 60 ms startup / 160 ms active / 260 ms recovery burst travels 105.6 units at 660 units/s regardless of frame partition. Crouching selects a low hitbox/pose. Down + forward + Kick slides without spending meter; down + Kick remains the sweep. Airborne Shadow aims at the current opponent hurtbox when released, with no homing afterward. `fighters.js` reuses authored sweep/flying-kick frames, while `renderer.js` draws the Nitro bar and hit multiplier directly over the arena without a background panel. Nitro uses a quick coil/strike/recoil sequence with a cached green sprite recolor, separate short-lived green echoes and directional flame ribbons; the fighter sprite remains opaque and hard-switched. The runtime source-atop atlas recolor preserves native alpha and never rewrites assets. Reduced motion retains the green color cue and omits moving decoration.

`index.html` owns seven labeled SVG action buttons and the pause-menu scale slider. `controls.js` updates Shadow without replacing its icon and toggles Nitro's `hidden` state at full meter. `styles/responsive.css` draws a round thumb arc: largest Punch at lower right, Kick beside it, Upper above Punch, Shadow at the arc's peak, Nitro above-left, Guard on the inner edge and Blink in the lower-left utility slot. The three-dot menu has a reserved 44 px gap between Blink and Kick on touch layouts; fine-pointer desktop retains a centered menu. Ability availability never moves other buttons.

`initControls` loads version-1 `inj-controls` (`{ version: 1, scale: 100 }`) before attaching its native range listener. Scale is bounded to 85–125% in 5% steps, separately from progression/audio. `setControlScale` updates the field/output and writes only on user adjustment; blocked/corrupt storage falls back to session/default values, and future schemas are preserved. `layoutControls` fits requested sizes to the current arena, keeps support targets ≥44 px and primary strikes ≥56/52 px, and reserves disjoint stick/menu regions. A binary fit sets shared `.screen` sizing/position tokens; portrait compacts the arc while wider arenas have a deeper curve. No CSS transform scales the whole deck or shrinks hit areas. `display.fitArena` calls this layout after setting arena dimensions, including when world width is unchanged, so resize/fullscreen/Home Screen safe areas remain aligned. The idle stick and captured ring use identical geometry; knob travel uses the measured radius. Existing independent capture and buffered combat arbitration are unchanged.

## Blue Velvet encounter boundary

`teddy.js` registers eight original theatrical moves on `MOVES`, plus `TEDDY_TUNING`. It loads after shared state/combat registration; `configureOpponent` only reads that tuning at runtime after all registration finishes. Combat delegates Teddy hurtboxes/attack stepping and Dummy control delegates its AI. The normal neutral sprite is 123.2 world units high, 110% of INJ's 112. Shrinking retains 34% of that height (41.888 units); the hurtbox and arena margins scale with it. Walking keeps indices 2/3: `drawTeddyFrame` routes index 2 to the separate `teddy-walk-left-v1.png`/`walkLeft` metadata and leaves index 3 on the original atlas. The alpha inspector normalizes the replacement to the previous step height and matches its lower-torso root to the unchanged right step, so normal/tiny and both facings use the same registration. The original sixteen-pose atlas is unchanged. Both forms share one 140 HP pool, without armor reduction or a refill. Low attacks and downward-aimed ground/aerial Shadow reach the tiny body.

During `fight`, `rounds.updateFlow` delegates to `stepTeddyShrink`. At HP ≤67%, it samples one delay in [0.45, 1.5) active seconds. The event waits for an in-flight Blink to finish; a lethal hit before the event still wins. The 2.35-second protected `shrink` state clears attacks, interrupted dodge/guard/counter actions, input, projectiles, particles and combo, freezes the round clock and cooldown, grounds both actors, and preserves health, Shadow/Nitro and cooldown resources. The renderer stages Doraemon's arrival, aim, beam, continuous anchored scale change and farewell. Low-pattern memory survives the cutscene. The tiny form uses 260-unit/s pursuit, three separate low punches per barrage, early leaping punches, anti-air and spinning slams. Threat guards have a reaction delay; short bursts end in explicit openings (220 ms tiny / 320 ms normal, followed by the rest of the pause). `state.js` owns the four-second `lowMemoryT` and shared repetition fields. `controlTeddy` observes distinct low attack objects even during knockdown/hitstun; after two lows it anticipates crouching pressure. Sweeps trigger physical hops, slides mix hops with brief guards/counters, and repeated crouch punches get a guarded recovery. The controller never cancels an active attack to dodge. Hop/backstep travel uses `dodgeFrom`/`dodgeTo`/`dodgeT`, with a finite 700–950 ms tiny cooldown, a visible 80 ms opening after travel, and a hop across the attacker when pinned at the edge. After connecting a punching burst, learned crouch pressure can trigger a recovery hop; the committed recovery still runs and high/aerial attacks or Shadow can hit the airborne body. Hop counters do not add invulnerability. Existing 250 ms knockdown wakeup protection is unchanged. All damage/guard/chip remains in shared combat, with the same 140 HP and no armor. Memory decays, varied high attacks reduce it, and reset clears it. Rendering never triggers the transformation or changes health. Reset clears the one-shot marker and size. Pausing freezes the event; reduced motion omits spin, entrance scaling and decorative beam motion.

## Velvet Colossus boundary

The third Teddy size is a **standalone level**, round five onward. Winning Blue Velvet still enters the normal player-paced victory; Next Round creates a fresh 1,200 HP Colossus and full-health INJ. A loss retries the boss's enlargement, not round four. `state.js` owns `giantEncounter` (one `minion`, `hazards`, `impact`, delayed health trail and one-shot reveal cue). Reset/restart and KO clear these pools. The boss's `giant` flag is separate from `tiny` and prevents the old shrink trigger.

`giant.js` registers four `GIANT_MOVES` after Teddy registration. `rounds.resetRound` configures the actor and starts protected `enlarge` rather than the normal intro. Over 4.8 seconds Doraemon returns, fires an enlargement ray, and Teddy grows from base scale 1 to exactly 2. The `enlarge` flow freezes controllers, damage, inputs, resources and cooldown; pause freezes its clock. `engine.js` also skips the completion tick. `roundTime` is `null`; the fight never checks/decrements a round timer, while combo expiry, Blink and AI clocks still run.

`giant-renderer.js` owns a 1→0.6 camera pullback about the fight center/ground baseline; the background starts cropped and the same pullback reveals the wider giant kingdom. INJ's model stays 112 units; Teddy ends at 246.4. The derived `encounters.fightWidth()` reads current `world.width / GIANT_TUNING.zoom` for this stage, and normal width elsewhere. Movement, shared physics, Blink, projectile cleanup, awakened footwork and resize use that combat extent; HUD/canvas/CSS still use `world.width`, with H=225. `display.js` shifts actors, echo, hazards, impact, attack target, particles and Blink origins by half the **combat** width delta. No cached viewport width or global fighter scaling is introduced. Reduced motion keeps the final wide camera, hard pose switches and static tells, omitting ray motes and summon scaling.

Every hit still damages the boss at full shared-combat damage. `combat.applyHit` preserves its attack object/clock/state, grounded position and zero hitstun/knockback, including sweeps, Nitro and charged Shadow. Boss damage does not add global hit-stop; rapid hits cannot stall its windup. Lethal damage still ends the fight. Four attacks cycle with long recovery and rest: **Kingdom Breaker** tracks only the first 550 ms of its 1.15-second windup, then locks facing; its front half-arena hand strike deals 20 damage, or 4 guard chip. Jumping alone does not bypass the hands. A late Blink gets behind the committed strike, while an early completed Blink can be reacquired. **Royal Footfall** sends two finite, jumpable/guardable ground waves. **Falling Ovation** drops three stars on fixed floor markers; they never home after marking. **Royal Recess** retreats for at most 850 ms, summons one echo, and rests for up to seven seconds. Echo defeat shortens the remaining recess. The boss stays damageable throughout.

The 40 HP summoned Dummy uses awakened decision/attack rules, a 450 ms materialization, normal hitstun/knockdown, and a ten-second maximum life. It is a separate `makeFighter` actor, never a replacement for `dummy`. `controlDummy` dispatches its awakened AI and preserves Blink's invisible-arrival rules for both actors; a resting Colossus keeps its folded-arm state during Blink. `combat.playerTargets()` lists living enemies, including protected/downed echoes; `playerTarget()` selects the nearest for normal facing and Shadow aim. Melee and Shadow resolve one intersecting target in nearest-first order; protected/downed echoes intercept rather than exposing the boss behind them. Eligibility is checked after selection. Switching the damaged actor resets `game.comboTarget` and combo scaling; reset clears the reference. Blink selects this same nearest combat target at activation and retains it through disappearance; if the echo expires before relocation, it reacquires the remaining enemy. Killing it clears only the echo, never the round. An echo or area hazard can cause a real INJ loss. KO clears every boss hazard/summon before victory/MiMi.

The renderer reuses the original Teddy atlas for neutral/walk/stomp/ovation and loads four new authored smash/recess poses through `teddy-renderer`/`teddy-frames.js`. Their scale normalizes to the standing folded-arm pose, not each pose's silhouette height. A separate full-width gold-framed segmented blue bar includes delayed damage, actual HP and compact INJ resources. Static direction/ground markers accompany the windup; the HUD distinguishes windup, active impact and safe recovery. The standard victory DOM remains player-paced, with a boss-specific underlying Canvas scene. No renderer changes HP, AI, hazards or progression. [Art provenance](../assets/giant-generation.md), [visual review](../artifacts/giant-review.md).

`audio.js` keeps the original arcade score and adds an original 88 BPM boss arrangement: half-time drums, low pulse, choir fifths and music-box melody. The existing audio scheduler selects `boss` for enlargement/fighting and uses its own step duration; normal rounds retain 112 BPM. Boss transitions reset the phrase, while mute/music preferences and node cleanup stay shared. Enlarging, windup, smash and summon have separate synthesized cues; no samples/downloads/dependencies.

## Teleport boundary

`state.js` owns `player.teleport` and `teleportCooldown`; `teleport.js` owns their lifecycle. `controls.js` routes BLINK / E; `movement.js` accepts it standing, crouching or airborne, while free to act. It cannot cancel attacks, hitstun or knockdown. The 460 ms action prevents attacks/damage while disappearing, relocates at 190 ms behind the opponent's **current** facing/position, then reveals INJ facing the opponent. Landing is grounded and clamped to the arena; corner side-switches gently separate the opponent inward to create rear space. The cooldown starts at activation and lasts 10 active fight seconds. Pause, hit-stop, intro, boss cutscenes and victory freeze it. Round/restart resets it; Goldline/shrink preserve it. `engine.js` also skips the final cutscene tick so controllers and cooldown never consume a whole cutscene-finishing delta.

`fighters.js` clips the crisp current pose with a shrinking/expanding horizontal window, rather than dissolving between sprites. `teleport.js` adds separate staggered line fragments; reduced motion omits those fragments. `display.js` shifts an in-flight origin with world resizes, while relocation reads current world bounds. Opponents commit existing swings toward the last seen side and reacquire after the 460 ms Blink, retaining a brief 120 ms opening rather than tracking an invisible arrival. Phone countdown text/accessible seconds update only when the displayed second changes, while the conic ring follows the same active-fight cooldown value each tick; the desktop HUD also shows ready/cooldown. The cooldown button keeps its fixed position and is labeled with `aria-disabled` while unavailable.

## Victory boundary

`combat.js` records `game.bestCombo` for the current round/encounter. `rounds.js` snapshots actual health, opponent and best combo in `game.victory` at an INJ win. A 1.1-second KO beat enters `victory`; losses retain their three-second beat and MiMi flow. A car clear still enters transformation and never opens a victory scene. Only robot defeat completes Goldline.

`beginVictory` clears combat effects/input and installs the authored victory pose. `engine.js` advances the scene clock while skipping fighter controllers, projectiles and damage; pause freezes it. `renderer.js` owns the dimmed arena, subtle uniform hero close-up, defeated opponent and deterministic gold flecks. Rendering never decides progression. `menus.js` fills/shows the accessible `index.html` victory panel, hides the touch deck/joystick via the scene class and focuses Next Round. The quiet menu moves to the bottom-left for this scene. `finishVictory` accepts Next Round or Enter/Space once and resets the round; restart/reset clear the panel, snapshot, best combo and effects. `audio.js` owns the short victory fanfare. Reduced motion uses the final static framing without gold motion.

## Pause cheats and native editing

`index.html` owns the cheat input (accessible name, placeholder, no visible label), live status, hidden five-option selector and Start level button. `menus.js` owns private session-only unlock state. Typing `INJ0` (case-insensitive, trimmed) reveals the selector immediately; submitting an unknown code only shows feedback. Start requires unlocked state and an open pause menu, validates a level in 1–5, sets the ladder to level minus one, and uses `resetRound()`/`resumeGame()` so all actors, pools, resources, timer and cutscenes follow normal initialization. It does not skip the Goldline car or boss reveal. Reload relocks; normal restart remains round one.

`controls.js` traps every visible enabled button/input/select inside the active dialog. Native editable controls, including the scale range, bypass combat/mute/Enter handlers; Escape retains pause/resume behavior. The pause overlay now uses viewport framing, a scrollable panel and 44 px native controls so the selector fits beyond the short portrait arena. Compact panel padding and row/section gaps preserve 44 px touch targets. Styling stays in `styles/layout.css`; there is no separate UI system or animation. The immersive gesture lock allows a single-finger drag on the paused native scale range, while retaining the existing multi-touch/page-gesture rules.

## Loss retry and stage boundary

`resetRound({ advance = true } = {})` rebuilds the current actors/resources and, by default, advances the ladder for victory/startup callers. `finishVictory` advances once; MiMi's `finishRoast` explicitly passes `{ advance: false }`, so Fight Again, Skip and dialogue keyboard completion retry the same level. KO and timeout losses use that same path. Losing the robot restarts the whole Goldline encounter from its car; losing tiny Teddy restarts full-size Teddy with an unused cameo. Restart still sets the ladder to zero before its advancing reset, returning to level one. Neither KO nor a loss dialogue increments the level itself.

`arena.js` preloads five local `arenaStages` images and derives `arenaStage()` from `game.round`: Cedar Courtyard, Storm Sanctum, Goldline Foundry Toybox Opera (round four), and Kingdom of Giants (round five onward). `arenaImg` remains an alias for the initial courtyard plate. No separate mutable current-stage state or combat RNG is involved. After opponent configuration, `resetRound` calls `paintArena`; resize and image load repaint too. Every load callback paints the current selection, so a delayed earlier image cannot replace the current stage. Missing/loading images use a stage-colored local procedural fallback. Goldline transformation and Teddy shrink retain their stage. The 400×225 plate camera preserves the 88% foot baseline; `renderer.js` applies the same camera to themed ambient light/motes. Reduced motion keeps static light and removes moving motes. Only Storm Sanctum draws the cosmetic duel, anchored to its new distant bridge. The original Hollow Temple PNG remains in the asset archive, unused by the current stages. [Art prompts and hashes](../assets/stage-generation.md).

## Tests, tools and records

- `node tests/structure.cjs`: local resource links, classic-script syntax, defer/bootstrap order and absence of production test hooks; no package dependencies.
- `node tests/browser.cjs`: consolidated runner, quick by default. `--suite` selects subsystem groups, `--all` selects all functional groups, `--full` explicitly invokes the preserved exhaustive `tests/full.cjs`. `--artifacts` enables supported captures; default runs never regenerate previews or render audio/slow reveal replays/run balance simulations. Each group reports elapsed time. See [testing.md](testing.md).
